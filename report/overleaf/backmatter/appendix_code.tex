\chapter{Code, Data and Complete Tables}\label{app:code}

\section{Code and data availability}

All the code used in this work is collected in a public repository:
\begin{center}
  \small\href{\repourl}{\nolinkurl{github.com/dhruv-solanki-2564/MSP-1_R_TIPPING_WEIN_BRIDGE}}
\end{center}
It contains the Arduino program that drives the staircase sweep and the trigger pulse, the LTspice
circuit files and scripts for Stages 1, 3 and 4, the analysis code that extracts envelopes, switching
points and cycle peaks from every recording (\cref{sec:analysis}), and the fitting and plotting code for
every figure and fitted value in this report.
The experimental and simulated recordings are available from the author on request.
